# Визуализация графа зависимостей Maven

Практическая работа по конфигурационному управлению, вариант 30.

## Общее описание

Консольная программа для визуализации графа зависимостей Java-пакетов
(формат Maven). Менеджеры пакетов и сторонние библиотеки не
используются: pom-файлы скачиваются и разбираются самой программой
(только стандартная библиотека Python: `urllib`, `xml`, `json`).

Готов этап 1: настройки читаются из JSON-файла, каждый параметр
проверяется, затем все параметры выводятся в формате ключ-значение.

## Функции и настройки

Все настройки лежат в JSON-файле (`config.json`):

| Параметр     | Описание                                              |
|--------------|-------------------------------------------------------|
| `package`    | пакет в виде `group:artifact:version` (в тестовом     |
|              | режиме - имя пакета, например `A`)                    |
| `repository` | URL репозитория Maven (`http`, `https`, `file`) или   |
|              | путь к файлу тестового репозитория                    |
| `test_mode`  | `true` - читать тестовый репозиторий из файла         |
| `ascii_tree` | `true` - вывести зависимости в виде ASCII-дерева      |
| `max_depth`  | максимальная глубина анализа (целое число >= 0)       |

Если в конфиге ошибка (нет файла, неверный JSON, нет параметра, не тот
тип или значение), программа печатает понятное сообщение и завершается
с кодом 1.

Модули:

- `src/config.py` - чтение JSON и проверка всех параметров;
- `src/main.py` - точка входа, вывод параметров.

## Сборка и тесты

Нужен только Python 3, сборка не требуется, сторонние библиотеки не
нужны.

    make test

или без `make`:

    python3 -m unittest discover -s tests

## Примеры использования

    python3 src/main.py config.json

Пример вывода:

    package: "junit:junit:4.13.2"
    repository: "https://repo1.maven.org/maven2"
    test_mode: false
    ascii_tree: true
    max_depth: 2

Если в конфиге ошибка, например `"max_depth": -1`:

    Ошибка: параметр 'max_depth' не может быть отрицательным
